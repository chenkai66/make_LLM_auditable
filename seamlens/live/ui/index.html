挂载到 Claude Code

让 seamlens live 监听某个项目的每次代码改动（写入该项目 .claude/settings.json 的 hooks，幂等）。
  1. 一次性挂载 hooks（把 <项目路径> 换成你的项目）： 
    复制python3 -m seamlens live --install <项目路径>
  2. 启动 god-view（就是当前这个页面）： 
    复制python3 -m seamlens live <项目路径>
  3. 之后在该项目里用 Claude Code 编辑代码 —— 每次写文件都会触发 PostToolUse hook，把改动 POST 到本服务，左侧图实时联动、右侧生成讲解。
