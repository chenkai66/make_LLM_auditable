挂载到 Claude Code

一条命令搞定：挂 hooks（幂等写入项目 .claude/settings.local.json）+ 扫描 + 起服务 + 开浏览器。
  1. 装一次（任选其一）： 
    复制pip install seamlens   # 或在仓库里 pip install -e .
  2. 一键启动 god-view（就是当前这个页面）： 
    复制seamlens live <项目路径>
  3. 之后在该项目里用 Claude Code 编辑代码 —— 每次写文件都会触发 PostToolUse hook，把改动 POST 到本服务，左侧图实时联动、右侧生成讲解。
AI 大脑（架构师 / 审计 / 问答）需要 claude CLI 在 PATH 且已登录；否则自动降级为模板讲解，不影响图谱联动。
